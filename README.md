# MULTIWORK — Executive Operating System

Premium executive command-center prototype.

## Deploy
Import this repository into Vercel. Vercel supports Git-based deployments and creates a preview URL for the deployment.

## Supabase
The MULTIWORK Supabase backend is configured separately. Production integration will use:
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

Do not commit secrets to this repository.
